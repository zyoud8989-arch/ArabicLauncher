# مشغل نوفا العربي (Nova Arabic Launcher)

مشغل أندرويد مفتوح المصدر وسريع وعالي التخصيص، مبني بالكامل بلغة **Kotlin** و **Jetpack Compose**، ومُحسّن بالكامل لدعم اللغة العربية وتدفق اليمين إلى اليسار (RTL).

## المميزات الرئيسية
1. **سطح مكتب وشبكة قابلة للتخصيص**: دعم أحجام الشبكة (4x4، 5x5، 6x6) مع إيماءات التمرير للأعلى لفتح درج التطبيقات وللأسفل للإشعارات.
2. **درج تطبيقات ذكي باللغة العربية**: بحث لحظي مع تجريد علامات التشكيل وتوحيد أشكال الهمزات، وفهرس أبجدي سريع على اليمين.
3. **نظام الشريط السفلي والمجلدات**: شريط سفلي (Dock) يدعم عدة صفحات، ومجلدات تفتح بنافذة منبثقة مع عناوين عربية قابلة للتعديل.
4. **شاشة إعدادات معربة بالكامل**: تخصيص أشكال الأيقونات، الخطوط العربية (Cairo، Tajawal)، والثيم الداكن (AMOLED).
5. **تسجيل المشغل كافتراضي**: معيارية كاملة عبر فلاتر `CATEGORY_HOME` و `CATEGORY_DEFAULT` في `AndroidManifest.xml`.

## متطلبات التشغيل
- Android Studio Ladybug أو أحدث
- JDK 17
- Min SDK: 26 (Android 8.0)
- Target SDK: 35 (Android 15)
